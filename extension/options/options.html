Model Garden Clicker options

How it works

The extension does what you would do by hand for each project and model: open the model's Model Garden page, click Enable, fill the questionnaire, click Next, tick the terms checkbox. One run, start to finish:

  1. Save the values once. Fill the Questionnaire below and click Save. The values stay in this browser's local extension storage.
  2. Pick projects and models. Click the toolbar icon, paste project IDs one per line, tick the models. Each pair is one job.
  3. Start. One console tab opens and the jobs run in order. Leave that tab alone while a run is active.
  4. DRY RUN (ticked, the default): Enable, fill, Next, tick the checkbox, stop. Agree is never clicked and nothing is purchased or enabled. Result dry-run.
  5. Full run (DRY RUN unticked): Start asks once more. Agree is clicked once per job, only on the Agreements page of the job's own project, product and exact model version. That is a Marketplace purchase billed to the project. Result done when the console reports "Successfully purchased".
  6. Step-by-step confirmation (either mode): a panel in the console tab waits for your Continue or Stop before Next and, in a full run, before Agree; in a dry run it ends with Next job or Stop. The popup header shows it as slow mode (snail icon) or kubardy mode (warning-sign icon).
  7. The badge, bottom-right in the console tab, updated every second: 
    MG Clicker [DRY RUN] job 2/4 · my-project · claude-haiku-4-5 · 00:37
step: waiting for Enable button · 12 s / 60 s
then: click Enable, then the questionnaire · next job: my-project · claude-sonnet-4-6
  8. Results. One row per job in the popup: dry-run, done, unverified (Agree clicked, no confirmation seen), skipped (already enabled), failed (with the reason) or stopped. The log keeps the last 50 lines.

These values are typed into the Model Garden questionnaire for every project. They are stored only in this browser's local extension storage (chrome.storage.local) and are never synced or sent anywhere by the extension.

Mode

While this box is ticked the extension fills the forms but never approves or enables anything, and stops on the Agreements page. Unticked means a full run: the extension clicks Agree, which makes purchases that bill the project.

Full run: every queued project and model will be purchased and billed. The popup asks once more before a full run starts.

The extension fills each page and then waits for you: a panel in the page offers Continue and Stop before Next and before Agree (in a dry run, Next job and Stop once the checkbox is ticked). If you click the console's own button yourself, the extension notices and continues. The popup's header shows this as "slow mode" (on) or "kubardy mode" (off) and can toggle it too.
